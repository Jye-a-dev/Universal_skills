# unslop

Created by Damir Sokolovsky ([@heydamir](https://x.com/heydamir)), who started the [Unslopping series](https://x.com/heydamir/status/2115063463063998736) on X. Case studies and visual references are available at [heydamir.design/unslop](https://heydamir.design/unslop).

unslop is a skill for Google Antigravity, Claude Code, and Codex that turns vibecoded, AI-looking UI into a designed interface with its own character. It finds the slop first, the purple gradients, glows, emoji labels, shouty copy and uneven spacing, then sets a direction from your product and fixes the screen pass by pass like a designer doing a redline review. It works in whatever your screen is built with, like Next.js, React, Vue, Svelte, Tailwind or plain HTML and CSS, on dashboards, apps and landing pages, directly inside the project codebase.

## Use

Trigger when reviewing or polishing a UI screen:

```
/unslop this dashboard
/unslop the hero section of the landing page
clean up this UI so it stops looking like an AI-generated template
```

It audits the screen and proposes a direction before it edits anything, so you can steer it early. If the screen is already good, it tells you so and suggests a few small refinements instead of redesigning it.

## What it does

- **Audit.** Lists every sign of slop with where it lives (see `references/signs.md`).
- **Direction.** Character, world, the one or two moments that carry the color, and a signature detail, all taken from your product.
- **Passes.** Spacing, color, icons, copy, type, layout, details, visuals and motion, in that order.
- **Tokens.** Applies strict 4px spacing rhythm and typography hierarchy (see `references/tokens.md`).
- **Visuals.** Shows your real product instead of generic glossy blobs or clichés (see `references/visuals.md`).
- **RTL Support.** Full right-to-left layout and typography rules for Arabic and Hebrew (see `references/rtl.md`).
